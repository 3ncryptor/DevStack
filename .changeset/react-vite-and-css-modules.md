React + Vite and CSS Modules (M4):

- **React + Vite** is a frontend choice next to Next.js: a single-page app with React Router, the
  same status, login, register, account and Todo pages, an `/api` proxy in development, and an
  nginx Docker image.
- **CSS Modules** is a styling choice next to Tailwind and plain CSS, for both frameworks.
